# Security reports

Do not post private keys, seed phrases, wallet files, RPC cookies or access tokens in issues.

The application is an experimental local mining wrapper. Keep node RPC on loopback, use an NVIDIA driver compatible with the CUDA build, and inspect startup CPU/GPU checks. HALTED markers require investigation; the application does not automatically clear them or restart failed mining.

For a suspected vulnerability, use GitHub private vulnerability reporting if available. If it is not enabled, open an issue asking the maintainer for a private reporting channel without including exploit details or secrets.

No independent security audit or binary code-signing claim is made.
